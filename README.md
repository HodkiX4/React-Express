# 🛒 Full-Stack E-commerce App

A fully functional e-commerce application built using **React**, **Express**, **MongoDB**, and **TypeScript**. It includes essential features like authentication, cart management, product listings, checkout, and order history.

> ⚠️ Note: The UI is still being polished, but all core features are implemented and working.

## 🚀 Features

- ✅ User authentication with session handling
- ✅ Product listing and detailed view
- ✅ Shopping cart with add/remove functionality
- ✅ Secure checkout
- ✅ Order history per user
- ✅ Profile management (email/password updates)
- ✅ Search and filtering
- ✅ Protected routes and session-based redirects

## 🛠️ Tech Stack

**Frontend:**

- React (with TypeScript)
- Zustand (for global state management)
- Axios
- CSS Modules
- react-hot-toast

**Backend:**

- Express.js
- MongoDB + Mongoose
- TypeScript
- JWT/token-based auth
